Política de privacidad

Última actualización: FECHA-DE-HOY

Esta política cubre la aplicación Hermes Agent (cliente OAuth hermes-agent-511820), una herramienta de uso personal autoalojada. El único usuario de esta aplicación es su propio autor, que es también el titular de la cuenta de Google cuyos datos se consultan.

1. Qué datos de Google se acceden

Con el consentimiento explícito del titular de la cuenta, la aplicación puede acceder a:

  • Gmail — leer y buscar mensajes, enviar mensajes, gestionar etiquetas y ajustes básicos.
  • Google Calendar — leer, crear y borrar eventos.
  • Google Drive — leer, subir, compartir y borrar archivos.
  • Google Docs y Sheets — leer y escribir documentos y hojas de cálculo.
  • Google Contacts — solo lectura, para resolver destinatarios.

2. Para qué se usan

Únicamente para ejecutar las tareas que el titular pide a su propio agente: vigilar correos de reposición de stock, preparar resúmenes, gestionar su calendario y trabajar con sus propios documentos. No se usan con ninguna otra finalidad.

3. Cómo se almacenan

El token de acceso se guarda cifrado en disco, en la infraestructura propia del titular, con permisos restringidos al usuario que ejecuta el agente. La aplicación funciona en local: no hay un servidor remoto operado por terceros.

4. Cesión a terceros

No se venden, alquilan ni comparten datos de usuario de Google con terceros. No se usan para publicidad ni para entrenar modelos. No se emplean para determinar solvencia ni para préstamos. El uso de los datos se limita a lo aquí descrito y cumple la Política de datos de usuario de los servicios API de Google, incluidos sus requisitos de uso limitado (Limited Use).

5. Conservación y revocación

Los datos se conservan solo mientras exista la autorización. El titular puede revocar el acceso en cualquier momento desde myaccount.google.com/permissions, lo que invalida el token inmediatamente; también puede borrar el token local del dispositivo donde corre el agente.
